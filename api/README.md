# PHP Backend for Pure Home Waters

This folder contains a basic PHP backend scaffold for the Angular app. It is designed to work with MySQL, but it also falls back to a mock database when no connection is available.

## What is included

- `index.php` — API router for CRUD operations and backups
- `db.php` — PDO-based MySQL adapter with a mock fallback
- `config.php` — database credentials and backup directory configuration
- `schema.sql` — MySQL table definitions to create the schema later
- `.htaccess` — rewrite rules to route `/api/*` requests to `index.php`
- `backups/` — storage folder for SQL backup files

## Supported endpoints

The API supports these resource routes:

- `GET /api/customers`
- `GET /api/customers/{id}`
- `POST /api/customers`
- `PUT /api/customers/{id}`
- `DELETE /api/customers/{id}`

- `GET /api/plans`
- `GET /api/plans/{id}`
- `POST /api/plans`
- `PUT /api/plans/{id}`
- `DELETE /api/plans/{id}`

- `GET /api/service-records`
- `GET /api/service-records/{id}`
- `POST /api/service-records`
- `PUT /api/service-records/{id}`
- `DELETE /api/service-records/{id}`

- `GET /api/payments`
- `GET /api/payments/{id}`
- `POST /api/payments`
- `PUT /api/payments/{id}`
- `DELETE /api/payments/{id}`

- `GET /api/customer-comments`
- `GET /api/customer-comments/{id}`
- `POST /api/customer-comments`
- `PUT /api/customer-comments/{id}`
- `DELETE /api/customer-comments/{id}`

- `POST /api/backups` — save backup SQL generated by the app

## How to enable MySQL

1. Update your credentials in `api/config.php`.
2. Create the MySQL database using `api/schema.sql`.
3. Serve the `api/` folder from a PHP-capable web server.

## Notes

- When MySQL is unavailable, the API will use a mock database implementation and continue returning valid JSON responses.
- The endpoints accept both camelCase and snake_case field names, so Angular payloads should work with the same model shape.
